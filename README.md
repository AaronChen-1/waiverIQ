# WaiverIQ

**Personal iOS Fantasy Football Analytics Companion**

WaiverIQ is an early-stage, independent iOS application designed to help fantasy football managers analyze their Yahoo Fantasy Football teams and make informed waiver wire decisions.

## Planned Features

- **Yahoo Fantasy Integration:** Secure OAuth 2.0 connection to retrieve authorized league, team, roster, and player data.
- **Waiver Wire Analysis:** Identify available players with strong recent performance and future potential.
- **Injury Opportunity Detection:** Highlight potential replacements for injured NFL starters.
- **Roster Optimization:** Recommend player additions and potential drops based on team needs.
- **Player Trend Analysis:** Evaluate recent production, usage, and changes in playing opportunities.

## Intended Use

The initial version is intended for one user managing one Yahoo Fantasy Football league. It is a personal, non-commercial development project.

WaiverIQ will request read-only access to Yahoo Fantasy Sports data. The application will not automatically execute transactions or modify Yahoo Fantasy rosters.

## Development Status

Planning and API access application stage. Yahoo Fantasy Sports API access has not yet been granted.

## Technology

- React Native / Expo for iOS
- Python / FastAPI backend
- Yahoo Fantasy Sports API
- NFL statistics and injury data sources
